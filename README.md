## Main technology
- Three.js 0.179.1 via import map
- GSAP 3.13.0
- GSAP ScrollTrigger
- HTML5 / CSS3 / ES6+

Three.js WebGLRenderer and WebGL2 capability detection are used for the 3D experience. ScrollTrigger is used for scroll-linked storytelling.

## Run locally
Use VS Code Live Server, or:
python -m http.server 8000

Then open:

## Notes
The 3D equipment is procedurally modeled with Three.js primitives so the project does not depend on a paid 3D asset pack. The visual system is intentionally optimized for a local portfolio demo.

The CGPA project can be attached by placing the final CGPA.html in the project folder and linking it from the project card. A final Mess Expense Calculator URL can likewise be added later.

## Browser
Use a modern browser with WebGL2 support for the full 3D experience.


## Certificate assets
Place these four files inside the `assets` folder using the exact filenames (including spaces):
- `certificate 1.jpeg`
- `certificate 2.jpeg`
- `certificate 3.jpeg`
- `certificate 4.jpeg`

The Certificates section automatically shows the images, supports hover effects, keyboard access, and opens each certificate in a full-size modal. If an image is missing, the card displays a clear placeholder instead of breaking the page.
